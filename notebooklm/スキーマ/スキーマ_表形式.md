# 農業水利施設ネットワークの表形式（GIS の属性テーブル）の説明

## 1. 対象とするデータ

このデータは，農業水利施設（パイプラインや開水路）のネットワークを表す．ネットワークは，附帯施設（ノード）と，附帯施設どうしを結ぶ水路施設（エッジ）からなる．附帯施設とは，水路施設以外の構成施設（T字管，曲管，制水弁，分水工，調整池など）の総称である．

## 2. 附帯施設の種類

## 3. ネットワークの基本的な考え方

1. **流れの向き**：各水路施設は，上流側の附帯施設から下流側の附帯施設へ水が流れる向きを持つ．
2. **次数**：附帯施設に接続する水路施設の本数を次数という．流入する本数を入次数，流出する本数を出次数という．データ中の接続の本数が2章の標準的な次数と異なる場合は，データ中の接続を優先する．
3. **境界点**：接続する水路施設が1本だけの附帯施設を境界点という．水路の上流端または下流端にあたる．
4. **分岐**：流出する水路施設が2本以上ある附帯施設を，分岐する附帯施設という．
5. **合流**：流入する水路施設が2本以上ある附帯施設を，合流する附帯施設という．
6. **最上流と最下流**：施設番号が1の附帯施設を最上流，施設番号が最大の附帯施設を最下流とする．
7. **幹線水路と支線水路**：最上流から最下流までの経路のうち，水路施設の数が最も少ないものを幹線水路とする．該当する経路が複数ある場合は，経路が最初に分かれる附帯施設で，下流を向いて右岸側にある経路を幹線水路とする．幹線水路以外の水路を支線水路という．
8. **右岸と左岸**：幹線水路上の附帯施設に立って下流を向いたとき，右手側に分岐する支線水路を右岸側，左手側に分岐する支線水路を左岸側という．右岸・左岸の区別は，幹線水路上の附帯施設から支線水路の先頭の附帯施設へ向かう水路施設にだけ記録する（右岸は R，左岸は L）．それ以外の水路施設には記録しない．

## 4. 記述形式：表形式

表形式は，GIS の属性テーブルに準じた形式である．ノード表とリンク表の2つの CSV（カンマ区切り）からなり，それぞれ1行目は見出し行である．

### 4.1 ノード表（附帯施設）

| 列名 | 内容 |
|---|---|
| node_id | 施設番号．N に続けて1から始まる整数（N1，N2，…） |
| type | 施設の種類（2章の記号） |

### 4.2 リンク表（水路施設）

| 列名 | 内容 |
|---|---|
| link_id | 水路施設の番号．E に続けて1から始まる整数（E1，E2，…） |
| from_node | 上流側の附帯施設の node_id |
| to_node | 下流側の附帯施設の node_id |
| bank | R（右岸）または L（左岸）．幹線水路から支線水路の先頭へ向かう水路施設にだけ書き，それ以外は空欄 |

### 4.3 施設番号と最上流・最下流

node_id の N の後の整数が施設番号である．3章6のとおり，施設番号が1の附帯施設が最上流，施設番号が最大の附帯施設が最下流である．

## 5. 記述例

記述例には，次のネットワークを用いる．

- ポンプ P（最上流）から T字管 T に接続し，幹線水路はファームポンド F（最下流）へ続く．
- 幹線水路の T字管から右岸側に支線水路が分岐し，その先頭は T字管である．
- 支線水路の T字管から，2つの曲管 L を経る水路と，制水弁 V を経る水路に分かれ，下流の T字管で合流して，給水栓 H に至る．

施設番号は，ポンプ＝1，幹線水路の T字管＝2，支線水路の先頭の T字管＝3，曲管＝4・5，制水弁＝6，下流の T字管（合流）＝7，給水栓＝8，ファームポンド＝9 である．

ノード表：

```csv
node_id,type
N1,P
N2,T
N3,T
N4,L
N5,L
N6,V
N7,T
N8,H
N9,F
```

リンク表：

```csv
link_id,from_node,to_node,bank
E1,N1,N2,
E2,N2,N3,R
E3,N3,N4,
E4,N4,N5,
E5,N3,N6,
E6,N6,N7,
E7,N5,N7,
E8,N7,N8,
E9,N2,N9,
```
