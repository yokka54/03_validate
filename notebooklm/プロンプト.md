# Notebook LM に入力するプロンプト

各プロンプトは、**新しいノートブック（または新しい会話）で1回ずつ**入力します。前の例題の回答が残った会話で続けて入力しないでください。
文面は一字一句そのまま使い、コピー＆ペーストで入力してください（文字列の手入力は誤りのもとになります）。

---

## 例1（5.2.1 SIFILES文字列から自然言語への変換）

```
次のSIFILES表記の文字列について，幹線水路において上流から2番目の分岐管に接続している施設と，すべての分岐の数を答えてください．

P[1]T(L>LT(C(LL1)(T1L1)T1H)H)T(E>)T(E>)F[1].
```
